Optimum PDF gathers in a single application what usually takes several tools: reading and annotating, text editing (down to a single word of an existing line, rich text with bold, italic, colours and links), page assembly and splitting, forms, professional headers and footers, Bates numbering, watermarks, password protection, digital signature, redaction, offline OCR, PDF/A export, images and scanner → PDF, batch processing and Office ↔ PDF conversion with no Microsoft Office or LibreOffice installed. Interface in 7 languages (French, English, Spanish, German, Italian, Portuguese, Dutch).

Edit

Text, images, shapes, links, detected lines and tables; undo / redo; alignment and object arrangement.

Pages

Merge, split, rotate, reorder, blank pages, page size (A5 to A0, Letter…) and margins, compression.

Print

Full print window (Ctrl+P): printer, paper, duplex, quality, page ranges; poster mode (an A0, A1 or A3 page on A4 sheets with crop marks and overlap), several pages per sheet, preview.

Convert

Word, Excel, PowerPoint, RTF, HTML, CSV, text and Markdown → PDF with the built-in engine; PDF → Word; image export.

Forms

Text fields, check boxes, radio buttons, lists, dates, signatures; filling and flattening.

Headers and footers

Six zones, {PAGE}, {NUMPAGES}, {DATE} fields, Bates numbering, logo, text or image watermark, saved templates.

Security and OCR

AES encryption, permissions, unlocking your own documents, offline text recognition (French, English).

Review

Standard PDF annotations (notes, highlights, shapes, ink, stamps), image signature, X.509 digital signature and verification, permanent redaction (text, images, paths), comparison of two PDFs.

Find and replace

Persistent search (case, whole word, accents), highlighted matches, replacement inside existing text, redaction of every match.

Built-in help

F1 help in 7 languages, keyboard shortcut list, start-up tips (can be turned off), mouse-wheel zoom centred on the cursor.

Images and batches

Images → PDF (JPEG, PNG, multi-page TIFF, WebP…), scanner input, batch processing of a folder (conversion, compression, PDF/A, protection, rotation, splitting, text, merge) with a CSV report.
